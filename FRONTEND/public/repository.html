README.md · Node Artifacts Specification

AI-GIT

A standalone, decentralized version control system designed explicitly for large AI/ML foundation models and neural network weights.

⚡ Quickstart CLI

# Clone repository metadata
ai-git clone AI-GIT

# Pull zero-copy deduplicated safetensors
ai-git pull origin main --weights

🧩 FastCDC Deduplication

AI-GIT splits checkpoints using Content-Defined Chunking (FastCDC), avoiding redundant storage of multi-gigabyte safetensors across training epochs. Unmodified layers are reused in MinIO / S3 with cryptographic content addressing.
