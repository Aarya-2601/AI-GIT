Quickstart with AI-GIT

This model repository tracks machine learning weights with chunk-level deduplication. Instead of storing multi-gigabyte safetensors redundantly across training checkpoints, AI-GIT's FastCDC engine slices weights dynamically into cryptographic chunks.

Clone & Pull Checkpoint

# Clone repo weights metadata
ai-git clone llama-3-8b-instruct

# Pull raw safetensors with zero-copy deduplication
ai-git pull origin main --weights

FastCDC Storage Savings

Training runs typically modify only a fraction of attention heads and MLP layers. AI-GIT automatically detects unmodified byte boundaries and reuses existing chunks in MinIO / S3, yielding 70%+ storage reduction.
